Почему этот курс

Ты работаешь в симуляторе

Курс разворачивается прямо в Claude Code или Codex, на твой выбор. Ты маркетолог команды Pulse и решаешь реальные задачи: контент, аналитика, GTM, вайбкодинг. Без лекций и слайдов, только практика.

Практика с первой минуты

Все модули это задачи внутри Claude Code или Codex. Ты учишься, делая реальную маркетинговую работу, а не смотришь на неё.

Один нарратив, один продукт

Весь курс про один стартап Pulse. Агенты, контент, дашборды живут в одном контексте, как в настоящей работе.

Шаблоны остаются с тобой

После курса у тебя готовый набор агентов и команд под маркетинговые задачи. Применяешь с первого дня.

Для кого

Узнаёшь себя?

Курс для тех, кто устал делать руками то, что можно делегировать.

Маркетолог
Пишешь контент-стратегию 3 часа, потом её переделывают. Хочешь выдавать черновик за 20 минут и итерировать быстро.
SMM-менеджер
Адаптируешь один пост под пять платформ вручную. Хочешь так: написал один, получил все форматы сразу.
Performance-маркетолог
CAC, ROAS, LTV: сводишь в Excel 2 часа. Хочешь дашборд из CSV за 20 минут с attribution по каналам.
Email-маркетолог
Пишешь онбординговую цепочку под каждый сегмент отдельно. Хочешь так: один промпт, три персоны, семь писем.
Контент-менеджер
Конкурентов смотришь руками: открываешь, копируешь, анализируешь. Хочешь 15 минут и готовый разбор.
CMO / Маркетинг-лид
Хочешь всю команду в едином голосе бренда. Одна командная память (CLAUDE.md / AGENTS.md), и Дима с Аней работают как ты.
Чему научишься

Навыки, которые остаются

После курса Claude Code или Codex это не «ещё один AI», а твой рабочий инструмент каждый день.

  • ✓ Настраивать AI-агентов под маркетинговые задачи: аналитик, копирайтер, SMM, стратег
  • ✓ Запускать параллельных агентов и анализировать трёх конкурентов за 20 минут
  • ✓ Считать CAC, LTV, payback period и строить дашборды с attribution по каналам
  • ✓ Писать контент-стратегии, GTM-планы и отчёты для CEO за один сеанс
  • ✓ Анализировать воронку конкурентов через web_fetch: лендинг, pricing, онбординг
  • ✓ Строить email-цепочки и контент-паки для разных платформ и персон
  • ✓ Вайбкодить: создавать лендинги без разработчика и деплоить на живой URL
  • ✓ Настраивать командную память проекта (CLAUDE.md / AGENTS.md), чтобы вся команда писала в едином голосе бренда
Что нужно

Требования

Минимум технического. Всё остальное объясняем в первом модуле.

Аккаунт Claude или ChatGPT
Для Claude Code нужна подписка Claude Pro или Max. Для Codex подойдёт ChatGPT Plus/Pro или ключ OpenAI. От $20/мес, бесплатные тарифы не поддерживаются.
Node.js 18+ (опционально)
Нужен только при установке через терминал. С десктопным приложением можно без него.
macOS или Windows 10+
Инструкции есть для обеих платформ. Linux тоже подходит.
Опыт в маркетинге
Базовое понимание маркетинговых задач. Программирование не нужно совсем.
